# Pre-registered reading of the re-run after the measurement fix (written before the run)

Date: 2026-09-12. Script: `scripts/experiments/newton/ratchet_rod_newton.py` at the commit
that introduces `rod_measure.py`. Old artifacts kept as `*.pre-measurement-fix-2026-09-12.*`.

## What was wrong (two independent defects, both fixed)

1. `joint_dtheta` computed `atan2(px, py)` of body **positions** — the azimuth of each body
   about the vertical — and differenced that. The rod lives in the x–z plane (`py ≈ 0`), so
   this was numerically undefined noise; the ratchet law itself consumed it. The 15,628°
   "Cobb" is this.
2. The permanent set was written to `joint_rod_rest_kb_local[:, 0]` in units of 1/m. Newton's
   rod joint stores the DER curvature binormal (an angle per joint) in the parent-local frame,
   bend about local **y** = component 1 for an x–z column. So the law prescribed rest bending
   about x (the y–z plane, which the x-shake and the gravity sag never enter), 48× too large.

Protocol otherwise unchanged: 9 conditions (`k_r` ∈ {0.3, 1, 6} yr⁻¹ × `B_g` ∈ {0.2, 0.3,
0.5}), `k_g,peak` = 1 yr⁻¹, 180 growth-months, 2 root-shake cycles/month at 4 mm, control run
with the law off.

## Outcomes and what each would mean (decided now, not after)

- **Sanity (must hold or the run is discarded, not interpreted):** Cobb in O(1–40°) for every
  world at every observation; `max |t_y|` (out-of-plane tangent) < 1e-3; control-run Cobb drift
  over 180 months < the 0.5° seed tilt × 10.
- **Gate A2 (control):** with the law off, `|Cobb(20 y) − Cobb(5 y)|` per world must be smaller
  than the law-on permanent set it is compared with. If not → shake-driven mechanics dominate,
  the experiment cannot see growth-driven ratcheting under this shake amplitude; report, do not
  retune the shake to pass.
- **Gate C (the claim under test):** mean |κ_p| at 20 y orders `k_r` 0.3 > 1.0 > 6.0 at every
  `B_g`.
  - PASS at all three `B_g` → the spatially resolved rod reproduces the scalar ratchet's
    ordering; the `rod/ODE` ratio column then says how far the local law departs from the
    scalar one (a ratio ≪ 1 or ≫ 1 is itself the finding, and is reported as is).
  - FAIL with sane Cobb → **a real null**: per-joint cementing driven by local elastic
    curvature does not order by restoration rate under this load protocol. Reported as a
    negative result for the rod extension; the scalar model's claim is unaffected either way
    because the scalar model imposes the ordering by construction (09-08 review §2).
  - Mixed (passes at some `B_g`) → reported per `B_g`; no post-hoc selection of the passing
    `B_g` as "the physiological one".
- Nothing here is clinical. The rod has no vertebrae, discs, muscles, ribs or growth plates.

## Correction to the smoke reading above (2026-09-12, before the full run reports)

The smoke numbers recorded in the previous section were **48× too large**: the observation
summed joint curvature (rad/m) over joints and called the sum degrees without multiplying by the
segment length (0.5/24 m). Found by the Codex continuation
(`reports/newton_readout_audit_2026-09-12/REVIEW.md`), fixed in `rod_measure.total_absolute_bend_deg`
and read back with `scripts/experiments/newton/ratchet_rod_readout.py`, which corrects the
running process's schema-1 output without touching the raw file (source SHA256 12b741f6…).
Corrected smoke values: total absolute planar bend **0.221–1.171°** across the nine worlds
(not 10.6–56.2°); absolute control drift **0.365 / 0.024 / 0.0005°** at B_g 0.2 / 0.3 / 0.5 (not
17.5 / 1.13 / 0.02°). The quantity is total absolute planar bend, not clinical Cobb. The
control drift was also mis-defined (experiment first sample subtracted from control last sample,
negatives clipped); it is now |control last − control first| per world. Observation ages are
end-of-month (recorded window starts at 5.083 y; there is no age-5 baseline sample).

Consequence for the pre-registered sanity block: its "Cobb in O(1–40°)" bound was set against the
2026-09-03 run's inflated magnitudes and every corrected smoke series lies **below 1°**. The
bound itself is therefore mis-scaled, not the measurement. **No change to the bound is made
here.** The choice — (a) amend the sanity range to the corrected units before the full run is
read, documented as a units correction unrelated to any outcome, or (b) leave it, report the
full run as descriptive only, and re-run under a new pre-registration — is recorded as an open
decision for the author on card t_40524ff0. Gate definitions (A1, A2, C) are unchanged either way.
The rod/ODE ratio column in the smoke table inherits the same factor (the scalar amplitude
κe0 was derived from the inflated bend) and is likewise not read.

## Amendment — adopted 2026-09-12 by the author (option (a)), before any full-run output existed

Reason: the sanity bound "Cobb in O(1–40°)" above was written against the 2026-09-03 run's
48×-inflated reporting scale. It is a units error in the bound, not a property of the rod. The
amendment changes only the magnitude window of the sanity block; **Gates A1, A2 and C are
unchanged in definition.** At the time of this commit the raw output file is still the
2026-09-03 artifact (the 180-month re-run, PID 994575, is in its developmental batch and has
written nothing), so no gate value has been seen by anyone.

Amended sanity block (must hold or the run is discarded, not interpreted):
- **Total absolute planar bend** (the quantity the `cobb` key stores; not clinical Cobb) between
  **0.05° and 10°** at every observation, in every world, experiment and control. Rationale: the
  0.5° seed tilt puts the stiffest column (`B_g` 0.5) near 0.22° in the corrected smoke; 10° is an
  order of magnitude above the largest corrected smoke value (1.17°), so anything outside is a
  measurement or solver failure.
- `max |t_y|` < 1e-3 (unchanged).
- Absolute control drift, |control last − control first| per world, < 5° (unchanged; this bound
  was derived from the seed tilt and was never on the inflated scale).
- A2 and the drift are evaluated over the **recorded window** (first sample at 5.083 y, after
  month 1; no age-5 baseline sample exists in this output) — acknowledged limitation, reported
  by the reader as such.

Reader: `scripts/experiments/newton/ratchet_rod_readout.py` applies these bounds by default and
records them in `readout.json`; `--bend-bounds 1 40` reproduces the pre-amendment reading for
the record. Git timestamp of this amendment = the commit that adds this section.
